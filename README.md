# Quickest_path_fuzzy_data
To run the case study, you need to download the map data from https://download.geofabrik.de/europe/germany/baden-wuerttemberg.html and place the file in the same directory as the "read_map.py" script. Next, run read_map.py to load the entire map data and save it as a temporary cache file, which helps save time when running the case study multiple times. Finally, run "case_study.py" to execute the algorithm for the case study.
